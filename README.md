# PARSER Project Page

Static project page for:

> **PARSER: Read in Parallel, Reason in Depth for Long-Context LLM Agents**

## Preview locally

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch** and choose the repository's default branch at `/ (root)`.

## Update resource links

The Paper, Code, Dataset, and Model buttons currently point to `./`. Replace their `href`
values in `index.html` when the public URLs are available.
